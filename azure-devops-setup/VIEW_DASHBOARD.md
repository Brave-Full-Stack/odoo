## 📈 Configure Azure DevOps Dashboard

### Quick Setup
1. Go to `Overview` → `Dashboards` → `+ New dashboard`
2. Name it: "Odoo Microservices - Sprint Overview"
3. Click `+ Add widget` and add:

**Recommended Widgets**:
- **Sprint Burndown** - Track remaining work
- **Sprint Capacity** - Monitor team capacity vs. work
- **Velocity** - View completed story points over time
- **Work Items by State** - Pie chart of New/Active/Closed
- **Sprint Overview** - High-level sprint statistics
- **Query Tile** - Custom work item queries

### Example Configuration

**Widget: Sprint Burndown**
- Team: Your team name
- Sprint: Sprint 1
- Chart type: Burndown

**Widget: Velocity**
- Team: Your team name
- Iterations: 6 (all sprints)
- Planning: Story Points

**Widget: Work Items by State**
- Query: `SELECT [System.Id] FROM WorkItems WHERE [System.IterationPath] = @CurrentIteration`

## 🔍 Troubleshooting

### "I don't see my sprints"
- Verify you're on the correct project: `Aries-Test/Odoo-Microservices`
- Check team settings: `Project Settings` → `Team configuration` → `Iterations`
- Ensure sprints are added to your team's iteration path

### "Dashboard is empty"
- Add widgets: Click `+ Add widget` on dashboard
- Configure each widget with your team name
- Select the correct sprint/iteration

### "Work items not showing in sprint"
- Run: `python3 azure-devops-setup/scripts/create_sprints.py` to re-assign
- Check work item iteration path in Azure DevOps
- Verify work items have the correct area/iteration path
